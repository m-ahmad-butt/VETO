# VETO final submission sources

The Markdown documents here are intended for Git. Generated deliverables are
stored locally in the ignored repository-root Evaluations/ folder:

- Evaluations/submission/VETO_FINAL_REPORT.pdf
- Evaluations/submission/presentation.html (arrow keys; N for notes)
- Evaluations/submission/presentation.pdf
- Evaluations/submission/VETO_BACKUP_DEMO.webm
- Evaluations/submission/screenshots/
- Evaluations/packages/VETO_PHASE4_SUBMISSION.zip

Compact results are versioned under ../evaluation/results/. Full raw evidence is
under Evaluations/runs/final-v1/. A fresh clone excludes these generated files;
restore the local archive or generate a new run using the documented tools.

Read COMPLETION.md for outstanding human confirmations, CONTRIBUTIONS.md for
member statements, and REPRODUCIBILITY.md for the commands (from veto/).
The historical PDFs and frozen run snapshots were moved byte-for-byte and retain
their original path descriptions; Evaluations/README.md records the relocation.
